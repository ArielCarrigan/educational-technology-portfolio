Interactive Web Design

Instructional Design | Educational Technology | Digital Learning

Welcome to my Interactive Web Design portfolio! This section showcases interactive learning activities I have developed using HTML, CSS, and JavaScript as part of my graduate coursework at the University of Florida.

These projects demonstrate my growing understanding of web development, interactive instructional design, and the use of technology to create engaging educational experiences. Each activity was designed to help students practice important mathematical concepts through active participation.

The projects featured below include an interactive absolute value quiz and two versions of an integer classification activity. Through these projects, I explored both traditional coding methods and AI-assisted development tools.

Absolute Value Quiz

An interactive five-question mathematics quiz designed to help students practice evaluating absolute values. Created using HTML and JavaScript, this activity provides immediate feedback on student responses.

Try the Quiz

Integer Classification: Traditional Coding

An interactive drag-and-drop mathematics activity designed to help students classify numbers as positive integers, negative integers, or numbers that are not integers. Developed using traditional HTML, CSS, and JavaScript coding methods, this project demonstrates my ability to modify and customize interactive learning activities.

Try the Activity

Integer Classification: AI-Assisted Coding

An interactive drag-and-drop mathematics activity developed with the assistance of Google AI Studio. Students classify numbers as positive integers, negative integers, or numbers that are not integers. This project allowed me to explore AI-assisted web development, troubleshoot generated code, and compare AI-based development with traditional coding methods.
